# P.R.O. MCP

Connect your Apple Health workouts, sleep and training progress to your AI assistant.

- **MCP server:** https://mcp.proapp.uk
- **Connection guide:** https://proapp.uk/mcp-connect
- **Demo:** https://proapp.uk/mcp-connect#demo
- **Privacy:** https://proapp.uk/privacy
- **Terms:** https://proapp.uk/terms

This repository contains the public MCP Registry metadata for P.R.O.

Connect through your assistant's OAuth flow and approve access in the P.R.O. iPhone app. You choose which data categories to share and can revoke access in P.R.O. Settings → MCP Connect.

MCP access is currently free. Recent data depends on syncing your iPhone. P.R.O. provides fitness and wellness information, not medical advice.
